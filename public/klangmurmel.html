Klangmurmel

Roll die Murmel über das Notenblatt. Jede Note, die du einsammelst, spielt einen Ton. Wenn du schnell hintereinander sammelst, wird die Melodie höher. Pass auf die Stacheln auf.

  • Handy neigen oder Finger aufs Feld halten: Die Murmel rollt in diese Richtung.
  • Doppelt tippen oder laut klatschen: Eine Schockwelle zerstört Stacheln in der Nähe.
  • Eine Note verschwindet nach ein paar Sekunden. Sammle sie vorher ein.
Neigen wird beim Start eingeschaltet
